# 水域弓字形巡游

加载固定地图并完成定位后，`area_patrol` 以点击开始时的船体中心为起点，在已知可航水域中选面积较大的一侧，生成往返的弓字形航线。滚刷全程关闭。计划与实际轨迹分别显示，航段完成后原地发停止命令并释放控制租约。

## 构建与离线预览

从工作空间根目录执行。预览的起点是地图坐标系中以米表示的船体中心。下面的起点位于仓库自带的小池地图中。

```bash
source /opt/ros/humble/setup.bash
colcon build --base-paths src --packages-up-to f1_operator_gateway --symlink-install
source install/setup.bash
ros2 run f1_area_patrol patrol_preview maps/lidar_20261021_145054.yaml \
  --start 0.062026 0.377296 --spacing 0.40 --png /tmp/patrol.png
```

PNG 中绿底为本次选中的水域，蓝线为巡游航段，橙线为连接航段，红点为起点。灰黑区域为未知或占用。命令输出选中面积、同一连通水域中跳过的面积、其他不连通面积，以及选中区域中航带未触及的格数。

## 接入 ROS 和 App

用现有 App 受管入口加载地图，或在本地启动固定地图组合入口。下面的命令以预览模式启动，共用同一个定位管理器，适用于已有扫描输入的环境。

```bash
ros2 launch f1_operator_gateway operator_bringup.launch.py \
  map:="$PWD/maps/lidar_20261021_145054.pbstream" start_bridge:=false output_enabled:=false
```

App 在“自动任务”中选择“水域弓字形巡游”。设置间距后点击“更新航线”。定位稳定后生成预览。点击开始后读取当前船位并确定本次航线。规划或控制权交接期间发生漂移时，从最新位置接入首段。蓝色虚线显示计划，绿色实线显示本次实走轨迹。设置在任务开始前生效，重新加载地图或重启控制器后恢复配置值。网关确认任务空闲并完成控制权交接后才允许启动。

| ROS 接口 | 用途 |
|---|---|
| `/area_patrol/path`、`/area_patrol/region` | RViz 添加 Path、Map，固定坐标系设为 `map`，Durability 选择 Transient Local。区域栅格 0 为选中水域，25 为同一连通区内跳过的水域，50 为不连通，-1 为作业范围外、占用或未知。 |
| `/area_patrol/actual_track` | RViz 添加 Marker，显示最近 2000 段有效位姿连线，暂停期间断线。 |
| `/area_patrol/plan` | 带地图和计划标识的完整折线，供网关转发。当前有效标识见 status。 |
| `/area_patrol/set_lane_spacing` | `f1_interfaces/srv/SetLaneSpacing`，参数 `spacing_m`。允许 0.10–10 m，且至少一个地图栅格。 |
| `/area_patrol/start`、`pause`、`resume`、`cancel`、`stop` | `std_srvs/srv/Trigger`。人工暂停保存断点，继续时从当前位置接入未完成航段。故障暂停需取消后重新开始。 |
| `/area_patrol/status` | JSON 状态，含启动阻因、航带进度、面积估计、地图及运行标识。 |
| `/area_patrol/command_preview` | 推进器预览。开启实际输出时，还需 bridge 授予租约才发布硬件命令。 |

## 区域、航线与覆盖率

规划器复用固定地图的自由栅格。海岸或池岸上被雷达标为自由的陆地需要用配置 `work_polygon_xy` 圈定水域。多边形坐标属于指定地图，给另一张图使用时应重新配置。从船位所在的原始自由栅格取四连通区域。与墙或未知区域相邻的自由栅格也可用于起步、连接和巡游。

沿可航连通区的长轴作一条经过船位的分界线，分别计算从船位出发、在各侧内部连通的栅格面积。选较大侧；面积相等时使用固定栅格方向。第一条航带从船位沿分界线向较长的可行方向行驶，后续航带逐行往返。窄水域可缩短首个换行间距。遇到凹口或岛时，分段并检查连接路径。结束后不为边角空隙生成补扫航带。

`lanes_done/lane_count` 表示已执行航带与计划航带数。`reachable_m2` 为选中面积，`skipped_m2` 为同一连通区内跳过的面积。实走带宽覆盖率以选中区域为分母，只累计巡游航段中的有效位姿带宽。完成条件为按顺序执行计划航段。

## 控制参数与现场核验

[默认配置](config/area_patrol.yaml) 的航线间距为 0.40 m。直行、近端、转向和横移初值分别是 22%、14%、20%、25% PWM。默认前视 0.45 m，航向误差超过 20° 时调整，回到 10° 内继续前进。到点半径取 0.18 m 与航线间距的 45% 中较小者；直线越过端点且横向误差在此范围内也可换行。普通横向漂移通过前视点逐步纠正。与船身接近垂直的连接段可用第五侧推。巡游节点使用共享定位状态和地图位姿。定位失效、位姿过期、船位越界、相邻控制采样位置跳变超过 0.35 m、持续无进展或租约撤销均停止输出。地图中新出现的临时障碍需人工处理。共享定位管理器继续使用雷达扫描判断定位有效性。

实船首轮应记录一条直线及一次完整换行的横向误差、漂移、停车距离和实际转向方向。这些参数为初始试验值。静态地图与二维雷达只描述其可观测范围。
