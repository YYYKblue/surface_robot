# 人工暂停续跑与地图删除、卸载

2026-11-11。适用于 Qt App、受管网关和矩形／开放多边共享控制器一起升级后的版本。

## 任务操作

App 提供开始、暂停／继续、取消。旧 `/pool_cleaning/stop`、`/l_cleaning/stop` 为取消别名，不再提供独立停止按钮。任务自然结束仍保留已有 COMPLETE 或单侧模式 STOPPED 语义。

- 人工暂停关闭全部任务输出并释放控制租约，保留路线、覆盖区间、墙段、换边目标和提速设置。暂停仍占用任务，禁止手动驾驶、另一任务、初始位姿重设、换图及提速修改。
- 继续通过 `task/resume`，以及两组 ROS Trigger `/resume` 服务发起。保持原 `run_id`；成功恢复增加 `resume_sequence`。网关等待请求之后的新鲜状态确认，重复 request_id 不重复执行，断线不自动重放请求。
- 暂停期间的时间不计入任务、换边及定时侧移动作的执行时长；恢复不重新执行整段侧移。基于位置和航向的动作保留原目标，重新计算输出。暂停期间不记录覆盖，轨迹分段。
- 恢复需要新鲜定位、控制器位姿、同一地图／定位轨迹／感知会话；沿墙阶段还需要暂停后的有效墙观测。相对暂停位姿的平移不超过 `edge_progress_jump_m`（默认 0.35 m），航向差不超过 20°。这是保守的恢复门限，仍需实船标定；不是路径可达或避障保证。
- 人工暂停之外的故障进入 `PAUSED` 且 `pause_kind=fault`，必须取消再开始；再按暂停不会把故障变为可恢复断点。RC 接管、桥连接／epoch 变化会使人工断点失效。
- 取消使断点失效、清除当前边关联，保留历史展示。取消期间迟到的租约回复释放其 token，不重启任务。
- 仅支持控制器持续运行期间的内存断点。App 重连可继续操作原任务；控制器重启、换图或断电后不能恢复。

状态新增 `pause_kind`、`paused_phase`、`can_resume`、`resume_blockers`、`resume_sequence`。网关能力新增 `task_resume`；旧控制器没有恢复能力时，新 App 禁用继续并显示原因。

```json
{"op":"task","action":"resume","task_type":"l","request_id":"resume-001","run_id":"当前任务编号"}
```

## 地图管理

受管入口 `operator_system.launch.py` 提供 `map_delete`、`map_unload` 能力。观察端不能执行写操作。执行中、人工暂停、故障任务未取消、任务结果未确认，以及已有地图操作处理中时拒绝写操作。

```json
{"op":"mapping","action":"unload","request_id":"unload-001"}
{"op":"mapping","action":"delete","name":"一号池","confirm":true,"request_id":"delete-001"}
```

- 当前地图必须先卸载再删除。卸载结束管理器拥有的定位／清洗进程组，等待旧节点退出，清空地图、位姿和轨迹，返回无地图待机。建图时必须先保存结束或放弃建图。
- 删除仅处理 maps 下指定名称的 `.pbstream/.yaml/.pgm`，不读取 YAML image 路径决定删除对象。允许删除残缺地图；禁止路径穿越、符号链接和目录。
- 待导出快照在列表中带 `snapshot_id`。删除快照须同时提交名称与该编号，只删除对应快照及占位文件，不按名称匹配多个快照，也不删除同名已发布地图。
- 文件先移动至 `maps/.delete-<id>/`；移动失败会尝试回滚。清理成功才报告成功。进程中断可能留下事务目录，其中 `delete.json` 的 `files` 按数组序号对应 `0`、`1` 等保留文件，路径相对于 maps；`state=staging` 表示移动可能未完成，`removed` 表示已全部移出原位置。重启不会自动清理这些事务，需检查清单后恢复或清理，不能当作三文件原子删除。
- 删除回复包含 `deleted`；App 刷新列表并关闭旧预览。删除不存在的普通地图返回 `already_absent=true`，重复请求不会误删其他地图。

## 验证与部署边界

单元测试覆盖暂停的路线／定时状态、恢复门控、请求去重及取消竞态，地图残缺文件、符号链接、快照身份、失败回滚和卸载等待。ROS 测试采用 localhost DDS、模拟反馈与模拟桥；Qt 测试采用 offscreen。

需要一起更新 Nano 上的清洗包、网关和 Windows App，无需修改 F103 协议。实船仍需验证输出归零、暂停漂移、墙角及换边途中恢复；软件测试不能替代这些验收。
